# Norte Padel V84 — Mobile App Experience

Mobile is now treated as a first-class app surface on screens <= 768px.

- Native-style top app bar with brand, live state, notifications and account.
- Fixed bottom navigation: Inicio / Torneos / Ranking / Cuenta.
- Account bottom sheet with profile, notifications, configuration and install entry points.
- Safe-area support for modern iOS/Android devices.
- App-like 100svh hero, touch targets, stacked results, horizontal match/sponsor rails and mobile-specific tournament/ranking layouts.
- Desktop structure and Supabase/data logic remain untouched.
